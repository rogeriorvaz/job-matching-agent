# Scoring

## Dimensions

| Dimension | Maximum |
|---|---:|
| Role alignment | 2 |
| Responsibility alignment | 2 |
| Technical skills | 2 |
| Agile / delivery | 1 |
| Leadership / seniority | 1 |
| Domain relevance | 1 |
| Location fit | 1 |
| Total | 10 |

## Penalties

Apply up to 3 points for material mandatory requirements that cannot be evidenced.

Do not treat optional preferences as mandatory requirements.

## Evidence

The model must distinguish explicit evidence, transferable evidence and missing evidence.

Missing information is not positive evidence.

## Future enhancement

Add a separate career-fit score so capability fit is not confused with strategic career fit.
